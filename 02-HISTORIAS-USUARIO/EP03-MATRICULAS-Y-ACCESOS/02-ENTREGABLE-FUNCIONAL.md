# EP03 — Entregable funcional para la review

## Producto obtenido

La Escuela puede conceder acceso gratuitamente o mediante una decisión administrativa, controlar
la matrícula y consultar sus resultados. El alumno encuentra el curso en “Mis cursos”.

## Historias incluidas

HU-017, HU-019, HU-020, HU-021 y HU-041.

## Guion

1. Ingresar con un alumno y confirmar una matrícula gratuita.
2. Comprobar que no se creó ningún pago ficticio.
3. Matricular desde administración a otro alumno con pago manual.
4. Matricular a un tercer alumno mediante exoneración.
5. Mostrar que no se aceptan duplicados, cursos cerrados ni sobrecupo manual.
6. Consultar las matrículas y sus condiciones desde administración.
7. Cancelar una matrícula individual con motivo y conservar su historial.
8. Ingresar como alumno y revisar “Mis cursos”.
9. Filtrar y exportar el reporte de matrículas.

## Criterios del incremento

- Las cinco historias cumplen sus criterios.
- Matrícula, condición económica y acceso conservan significados separados.
- El curso aparece una sola vez para el alumno.
- Un acceso cancelado o vencido no abre el aula.
- El reporte coincide con las matrículas operativas.

## Límite

EP03 entrega el acceso, pero el aula y el progreso se desarrollan en EP04. El pago automático con
Culqi permanece reservado para EP06.
